内容黑名单

拉黑内容及导出配置。

    此页面能够帮助你将网站中你想隐藏的内容放入“黑名单”中。 例如，在你使用自制内容时，你可以只展示需要的内容，而将无关内容放到黑名单中。 This page allows you to create configurations which "blocklist" site content, hiding it from list pages. This can be used, for example, in conjunction with homebrew content, to create a campaign JSON file containing additions to the base game, as well as the removal of extraneous content.

If you are a DM intending to use this system to remove parts of the game you consider broken; inconvenient; or otherwise in need of adjustment, please first consider the needs and expectations of your players, as well as the extensive playtesting and design iteration backing 5th Edition.
